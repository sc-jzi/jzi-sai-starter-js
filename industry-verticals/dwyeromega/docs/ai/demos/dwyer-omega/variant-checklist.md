Hero Banner must be **DwyerOmega**. The Default variant does not render Quick Order.

Featured Products Carousel and Industry List use the same layout for Default and DwyerOmega, so they look right before the variant is selected.

Steps per component:

1. Click the component on the canvas.
2. Open the Design tab in the right-hand pane.
3. Select the variant from the dropdown.

Footer also needs datasource `Dwyer Omega - Footer` (`{6495000B-1365-4C6C-90EC-CC03AB770336}`).
