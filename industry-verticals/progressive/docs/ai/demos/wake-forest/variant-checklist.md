# Variant Selection Checklist

Open Home in Pages editor and set these variants:

| # | Component | Current | Needed | Notes |
|---|-----------|---------|--------|-------|
| 1 | Hero | Default | **WakeForest** | Centered headline over full-bleed image |
| 2 | Three Column CTA | Default | **WakeForest** | Gold button row (Majors, Visit, Apply) |
| 3 | Two Column CTA (Wake Up) | Default | **WakeForest** | Dark text panel + image |
| 4 | Two Column CTA (Motto) | Default | **WakeForestMotto** | Seal + motto text |

**Steps per component:**
1. Click the component on the canvas
2. Design tab → Variant dropdown
3. Select the WakeForest variant
4. Save

> Variant Definition items must exist in Sitecore before they appear in the dropdown. See `manual-tasks.md` §2.
